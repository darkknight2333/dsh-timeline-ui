# 截图与录屏说明

README 与 Release 需要两张图：

1. `docs/media/sidebar.png` — 侧边栏按日期分组（今天 / 昨天 / 月日），带编号与「查看全部」。
2. `docs/media/rail.gif` — 鼠标沿导航条上下移动，波峰跟随（3～5 秒即可）。

## 为什么仓库里暂时没有

这个插件是在没有浏览器控制的自动化会话里开发与测试的：可以跑代码级测试，但无法截图或录屏。因此**不放占位图，也不放合成图**——那会被误认为真实界面。

## 采集要求

- **换成演示内容**：新建一个临时 profile 或临时工作区，造 6～10 个假会话（例如“周报草稿”“论文翻译”“波导笔记”），不要把真实会话标题放进画面。
- **隐藏隐私**：窗口标题、头像、账号名、工作区路径、右下角余额挂件、任何 API Key 都不能入镜；路径可用纯色块遮挡。
- **明暗各一张**（可选）：主题差异主要体现在横线灰度与编号灰阶。
- GIF 只需覆盖“鼠标进入 → 上下移动 2～3 格 → 离开恢复”这一段，帧率 15～20 fps，宽度 600～800 px。

## 采集后

```bash
mkdir -p docs/media
# 把文件放到 docs/media/ 后，README 中替换：
#   ![侧边栏](docs/media/sidebar.png)
#   ![鱼眼悬停](docs/media/rail.gif)
```

GIF 建议控制在 3 MB 以内；超过时改用 mp4 或缩短时长。
